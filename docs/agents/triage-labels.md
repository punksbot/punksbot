# Étiquettes de triage

Les compétences d’ingénierie parlent en termes de cinq rôles canoniques de triage. Ce fichier associe ces rôles aux chaînes d’étiquettes GitHub utilisées dans `punksbot/punksbot`.

| Rôle canonique | Étiquette GitHub | Signification |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Le responsable doit évaluer le ticket |
| `needs-info` | `needs-info` | En attente d’informations de la part de l’auteur du ticket |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifié et prêt pour un agent AFK |
| `ready-for-human` | `ready-for-human` | Nécessite une intervention ou une mise en œuvre humaine |
| `wontfix` | `wontfix` | Le ticket ne recevra pas de suite |

Lorsqu’une compétence mentionne un rôle canonique, utilisez la chaîne d’étiquette GitHub correspondante dans ce tableau.

Modifiez la colonne « Étiquette GitHub » si le vocabulaire réel du dépôt change ultérieurement.
