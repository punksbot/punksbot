# Livrer d’abord la recherche lexicale avec D1 FTS5

La première livraison projette les contenus recherchables dans des index D1 FTS5 afin de préserver la recherche lexicale de Punks. Vectorize, les embeddings et le classement sémantique sont différés jusqu’aux spécifications Punks correspondantes plutôt que d’introduire une nouvelle sémantique pendant la migration.
