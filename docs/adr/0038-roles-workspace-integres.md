# Fournir quatre Rôles de Workspace intégrés

Les Punks reçoivent dans chaque Workspace un rôle Propriétaire, Modérateur, Membre ou Invité. Chaque rôle est un ensemble versionné de permissions explicites évaluées par le même moteur d’autorisation ; aucun rôle global du Compte Punks ne se propage implicitement dans un Workspace. Les rôles personnalisés sont différés aux spécifications Punks UI sans modifier le modèle de permissions sous-jacent.
