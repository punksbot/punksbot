# Préserver la parité fonctionnelle complète avec Buzz

La migration Cloudflare Native n’est achevée que lorsque toutes les capacités de production de Buzz fonctionnent contre le nouveau backend, notamment les conversations temps réel, le journal d’événements signé, les Workspaces, les médias, Git, la recherche, les huddles, l’administration et les clients web, desktop et mobile. Une migration limitée au cœur social ou à un import structurel ne constitue pas la parité attendue ; la refonte Punks UI reste une phase ultérieure.
