# Authentifier les Punks avec Google ou GitHub

Un Compte Punks peut utiliser Google ou GitHub comme moyen de connexion, avec une passkey facultative. Les identifiants des fournisseurs restent des moyens d’authentification liés au Compte Punks global plutôt que l’identité du Punk elle-même, afin que les appartenances aux Workspaces ne dépendent pas d’un fournisseur particulier.
