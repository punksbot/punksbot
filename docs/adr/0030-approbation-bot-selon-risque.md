# Soumettre les actions de Bot à une politique de risque hybride

Les capacités ordinaires peuvent être accordées durablement à une installation de Bot. Une action sensible exige par défaut une approbation ponctuelle ; un Propriétaire de Workspace peut la remplacer par une capacité permanente seulement si son périmètre, son budget, son expiration et ses ressources sont explicitement bornés. Toute demande, approbation, exécution et révocation est attestée dans le journal interne.
