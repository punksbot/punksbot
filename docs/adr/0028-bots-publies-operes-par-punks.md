# Exécuter seulement des Bots publiés et opérés par Punks

La première livraison n’exécute côté serveur que la logique de Bots publiée, revue et opérée par l’Opérateur Punks. Un Propriétaire de Workspace peut installer, configurer, limiter ou retirer ces Bots, mais ne peut pas téléverser de code arbitraire. Les intégrations externes futures resteront derrière une couture de capacités sans obtenir un accès direct au runtime interne.
