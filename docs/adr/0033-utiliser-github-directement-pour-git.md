# Utiliser directement les endpoints GitHub pour Git

Les Punks utilisent les URLs et les autorisations GitHub pour cloner, récupérer et pousser ; Punks Bot ne fournit pas de proxy smart-HTTP Git sous punks.bot. Punks UI accède aux fonctionnalités Git au moyen d’un jeton utilisateur de la GitHub App, tandis qu’une Installation de Bot utilise un jeton d’installation à durée courte, ses capacités Punks et les approbations requises.
