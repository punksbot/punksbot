# Faire contribuer les Bots par Pull Request par défaut

La capacité Git ordinaire d’une Installation de Bot permet de créer ou mettre à jour une branche et une Pull Request, pas de pousser directement sur la branche par défaut. Un direct push exige une capacité distincte limitée à un Repository et à des branches précises, avec la politique renforcée d’approbation, de budget, d’expiration et d’attestation applicable aux actions sensibles.
