# Cibler uniquement la compatibilité Punks

La parité avec Punks porte sur les capacités fonctionnelles offertes aux Punks et aux Bots, pas sur la compatibilité wire avec les clients Punks ou l’écosystème externe. Les protocoles, endpoints et clients peuvent donc évoluer ensemble lorsque cela produit une architecture Workers plus profonde, tandis que chaque comportement retenu reste couvert par la matrice de parité.
