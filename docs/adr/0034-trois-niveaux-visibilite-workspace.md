# Distinguer trois niveaux de visibilité de Workspace

Un Workspace est privé, visible par les Punks authentifiés, ou public sur Internet. La lecture, la découverte, les projections de recherche et les caches appliquent le niveau choisi ; l’écriture exige toujours une appartenance et une autorisation. Le niveau public autorise une lecture anonyme, alors que le niveau Punks interdit cette lecture sans session.
