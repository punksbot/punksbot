# Utiliser TypeScript par défaut et Rust/WASM de façon ciblée

Le Worker d’entrée, les Durable Objects, les modules métier, les contrats et les adaptateurs Cloudflare sont implémentés en TypeScript. Rust/WASM est réservé aux algorithmes purs, aux codecs ou à la cryptographie lorsque leur portabilité et leur bénéfice sont démontrés, plutôt que de tenter de porter les dépendances serveur Rust de Punks.
